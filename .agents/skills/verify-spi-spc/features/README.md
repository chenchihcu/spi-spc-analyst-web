# SPI·SPC 使用者操作地圖

| 功能 | 本機種子與可觀察結果 |
|---|---|
| [資料庫瀏覽](database.md) | 空白 D1。資料庫分頁與選擇器顯示空狀態，使用者重新整理觸發成功的資料查詢。 |
| [管制圖](control.md) | 示範回合。主管制圖與 CL 摘要可讀。 |
| [3D 焊墊位置](sim3d.md) | 示範回合切板與 HUD。受控座標、純示意網格需不同資料。 |
| [分析報告預覽](report.md) | 示範回合切換章節，預覽隨之更新。 |

`verify.py database` 只跑首項，`verify.py all` 走四項。同一 Chrome 工作階段依序操作，各項的額外入口與資料前提分別記錄。
