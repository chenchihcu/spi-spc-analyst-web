# 原始量測檔與規格數值正確性驗證（`accuracy`）

## 目的
以 Python 獨立解析原始量測 CSV 與規格上下限（Spec v1／Spec v2）算出真值（ground truth），逐一核對 UI 畫面與匯出檔的計算結果是否完全吻合，而非只確認畫面有渲染。

## 步驟與驗收條件
1. 動態產生確定性測試資料（4 板 `B001`–`B004` × 4 元件 × 2 焊墊 = 32 筆量測），在預設規格（體積 `70–130%`）下刻意設計剛好 **2 筆超規**（`B002/R1-1` = `62.0%`、`B004/U1-2` = `138.0%`），其餘項目（高度、面積、X/Y 偏移）皆在規格內。
2. 透過介面登錄受控座標、匯入量測檔並儲存預設料號規格 v1（`70–130%`）。
3. **總覽 KPI 核對（全板）**：核對 `#kpis` 顯示的平均體積（1 位小數）、整體標準差 σ（樣本標準差 `ddof=1`，2 位小數）、不良焊墊數（`2 處`）、不良 PPM（`62,500`）與樣本數（`4 片板 · 8 個焊墊位置`）。
4. **單一群組 Ppk 核對（`0402`，n=16）**：切換 `#selGroup` 至 `0402`，核對該群組的平均體積、整體 σ 與精確 `Ppk = min((USL - μ)/(3σ), (μ - LSL)/(3σ))`。
5. **管制圖 CL 核對**：進入 `control` 分頁，解析 `#ctrlSub` 的 `CL` 值並核對與原始資料均值誤差 ≤ 0.05。
6. **3D HUD 單板統計核對**：進入 `sim3d` 切換 `B002`，核對 `#hud` 顯示 `8 焊墊`、`不良 1` 與 `B002` 真實平均體積。
7. **匯出 CSV 核對**：透過匯出中心下載 `def-csv`（不良焊墊明細表）與 `board-csv`（各板統計彙總表），以 Python `csv.reader` 核對不良明細剛好 2 筆（`B002`/`R1-1`/`62.0`、`B004`/`U1-2`/`138.0`）且各板均值吻合真值。
8. **規格變更敏感度核對（Spec v1 → v2）**：於「錫膏印刷規格設定」將體積 LSL 由 `70` 收緊為 `98` 並儲存為新版本 v2，回到總覽確認不良焊墊數與 PPM 精確更新為新規格對應的真值。
9. 清理測試紀錄（批次刪除 SPI 與座標檔），確認 D1 歸零。
