# RFC-SPI-PAIR-UX-20261112：量測與座標成對呈現

**狀態**：實作中  
**範圍**：記錄庫與匯入第 ① 步的呈現與操作路徑。不改 D1、`place_id`、`placeProof`、位號演算法，也不提供事後改綁。

## 1. 問題

量測紀錄與座標檔必須符合同一料號、同一版次，且量測面落在座標面別內。上傳、下載與清單把兩份檔拆開：座標登錄在記錄庫的座標分頁，量測匯入在五步驟的第 ① 步只能挑選已有座標。清單要按「驗證」才看得到對應。列上的「匯出」與頂欄報告匯出用同一個詞。

## 2. 記錄庫

預設分頁是「配對」。規格與稽核維持獨立分頁。量測清單與座標清單仍保留，供既有選取路徑使用，不作為預設入口。

配對卡以料號與版次為標題。卡內先列該版次的座標檔，再列引用它且身分相符或身分不符的量測。尚未搭配、座標檔不存在，以及沒有任何量測引用的座標，放在清單頂端「未成對」。

每一筆量測用清單已有欄位顯示一種狀態：

| 狀態 | 條件 |
|---|---|
| 身分相符 | 有引用、座標還在，料號與版次相同，量測面在座標面別內 |
| 身分不符 | 有引用且座標還在，但料號、版次或面別有一項不同；寫出第一項 |
| 座標檔不存在 | 有引用，清單中沒有該座標 |
| 尚未搭配 | 沒有座標引用 |

位號筆數與原檔指紋仍只在對應證明。量測的證明按鈕文字是「對應證明」。座標槽顯示「被 N 筆量測引用」；N 為 0 時寫「尚無量測引用」。點筆數展開批號與面別，不必先開整份證明。

篩選保留料號、面別，以及只作用在量測列的合格／異常。另加：未搭配、座標檔不存在、座標無引用。

## 3. 上傳

配對卡的空座標槽提供「登錄座標檔」，料號與版次由卡片帶入。存入後停在該卡，焦點在「匯入量測」。

「匯入量測」打開既有五步驟，並帶入料號、版次、面別與這張卡已選的有效座標。第 ④ 步這些欄位仍可改。一改就在該欄位旁標出與所選座標不符的項目。

從「＋ 匯入新檔」進入時，第 ① 步在料號、版次、面別都有值之後列出符合的有效座標，並提供「先登錄座標檔」。登錄完成後回到這一步，且已選取剛存的檔。畫面上寫明位號與原檔指紋於套用時由伺服器確認。

空的座標清單不再寫「或於匯入時上傳」。

## 4. 下載與動作

列上的原檔下載稱為「下載原檔」。配對列另有「下載這一對」：量測原檔與所引用的座標原檔各下載一次。座標不在時該動作停用，並寫「座標原檔不在，只能下載量測原檔」。

量測列的主要動作是「載入分析」，座標列是「選取」。其餘收進「更多」。頂欄「匯出」仍只負責報告與分析產出。

## 5. 頂欄

`#stateSpi` 與 `#statePlace` 仍是狀態，不是選單，兩顆都只描述目前分析回合（v10.23.1 起；定義在 `loadStateModel`）。燈號：綠＝受控且已用於分析，琥珀＝已用於分析但未受控或狀態待確認，灰＝沒有用到，紅＝失敗。錯誤與原因寫在膠囊文字上，不只靠顏色。

| 膠囊 | 情況 | 燈 | 文案 |
|---|---|---|---|
| 量測紀錄 | 有效受控紀錄 | 綠 | 已套用（受控）・N 個位號無座標 |
| 量測紀錄 | 舊資料／待判定／已被修正／無法確認 | 琥珀 | 舊資料・未受控（已用於分析）／待管理者判定／歷史修正前版本／狀態無法確認 |
| 量測紀錄 | 範例或沒有來源 | 灰 | 未套用 |
| 座標檔 | 受控連結 | 綠 | 已套用（身分相符）／已連結 |
| 座標檔 | 舊資料回合的檢視套用 | 琥珀 | 已套用（檢視，未受控） |
| 座標檔 | 已選取但沒用到目前回合 | 灰 | 未套用（已選 料號 版次，原因） |
| 座標檔 | 座標檔不存在或身分不符 | 紅 | 不存在（已連結）／不符原因 |

不再單獨顯示「已選取」：選取屬於匯入表單（`#placeState`），不是回合狀態。

## 6. 驗收

- 空座標清單不含「於匯入時上傳」。
- 配對卡能看出尚未搭配與座標檔不存在。
- 從配對卡匯入時，料號、版次、面別已帶入。
