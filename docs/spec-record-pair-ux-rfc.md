# RFC-SPI-PAIR-UX-20261112：量測與座標成對呈現

**狀態**：實作中  
**範圍**：記錄庫與匯入第 ① 步的呈現與操作路徑。不改 D1、`place_id`、`placeProof`、位號演算法，也不提供事後改綁。

## 1. 問題

量測紀錄與座標檔必須符合同一料號、同一版次，且量測面落在座標面別內。上傳、下載與清單把兩份檔拆開：座標登錄在記錄庫的座標分頁，量測匯入在五步驟的第 ① 步只能挑選已有座標。清單要按「驗證」才看得到對應。列上的「匯出」與頂欄報告匯出用同一個詞。

## 2. 記錄庫（v10.35.0 起：以量測清單為主）

v10.19～v10.34 的預設分頁是依料號與版次分組的「配對」卡，未成對置頂。實測手機 390px 上清單只剩 215px 高，且要捲過未成對區才到可載入的量測；主要工作是「找一筆量測載入分析」，不是檢視配對關係。v10.35.0 移除配對頁，改為下列設計。

分頁：量測記錄（預設）、座標檔、規格與稽核。三顆分頁按鈕都可見。

量測與座標共用一種清單列，桌面與手機同一份標記，依上傳時間新到舊：

| 列 | 內容 | 主鈕 |
|---|---|---|
| 量測 | 批號、狀態與品質徽章；料號 版次 · 面別 · 製令 · 量測日期 · 板數與焊墊數；座標對應狀態；檔名 · 上傳時間 · 上傳者 | 載入分析 |
| 座標 | 料號 版次 · 面別、狀態徽章；元件數 · 單位；被 N 筆量測引用；檔名 · 上傳時間 · 上傳者 | 選取／套用到目前回合 |

每列在「⋯」選單外最多一顆主鈕。其餘動作都在該列「⋯」選單。

量測的座標對應狀態沿用 `measurementLink`，依完整清單判定，不受搜尋與篩選影響：

| 狀態 | 條件 |
|---|---|
| 座標身分相符 | 有引用、座標還在，料號與版次相同，量測面在座標面別內 |
| 身分不符 | 有引用且座標還在，但料號、版次或面別有一項不同；寫出第一項與所引用的座標 |
| 座標檔不存在 | 有引用，清單中沒有該座標 |
| 尚未搭配 | 沒有座標引用 |

位號筆數與原檔指紋只在對應證明。座標列顯示「被 N 筆量測引用」；N 為 0 時寫「尚無量測引用」。點筆數展開批號與面別。

篩選：搜尋框常駐；料號、面別、品質（只在量測頁）在工具列，手機寬度收進「篩選」鈕。對應狀態是帶筆數的快速篩選：量測頁「尚未搭配座標 N」「座標檔不存在 N」，座標檔頁「無量測引用 N」；N 為 0 且未啟用時不顯示。換分頁時不沿用另一種紀錄的對應篩選。

版面：對話框的標題、工具列、頁尾固定，只有清單區捲動。分頁內不得再設高度上限或第二個捲動區，清單上方不得常駐表單（`tests/record-picker-layout.test.mjs`）。

## 3. 上傳

管理者在座標檔頁按「＋ 登錄座標檔」或「＋ 登錄板面圖檔」才展開表單。「尚未搭配」的量測可從「⋯ → 登錄座標檔」切到座標檔頁，表單帶入料號與版次。存入後新列標亮並捲到該列。

座標列「⋯ → 匯入量測」打開既有五步驟，並帶入料號、版次、面別與該座標。第 ④ 步這些欄位仍可改。一改就在該欄位旁標出與所選座標不符的項目。

從「＋ 匯入新檔」進入時，第 ① 步在料號、版次、面別都有值之後列出符合的有效座標，並提供「先登錄座標檔」（開啟座標檔頁並展開表單）。登錄完成後回到這一步，且已選取剛存的檔。畫面上寫明位號與原檔指紋於套用時由伺服器確認。

空的座標清單不寫「或於匯入時上傳」。

## 4. 下載與動作

原檔下載稱為「下載原檔」。量測列另有「下載這一對」：量測原檔與所引用的座標原檔各下載一次；座標不在時不提供。頂欄「匯出」仍只負責報告與分析產出。

## 5. 頂欄

`#stateSpi` 與 `#statePlace` 仍是狀態，不是選單，兩顆都只描述目前分析回合（v10.23.1 起；定義在 `loadStateModel`）。燈號：綠＝受控且已用於分析，琥珀＝已用於分析但未受控或狀態待確認，灰＝沒有用到，紅＝失敗。錯誤與原因寫在膠囊文字上，不只靠顏色。

| 膠囊 | 情況 | 燈 | 文案 |
|---|---|---|---|
| 量測紀錄 | 有效受控紀錄 | 綠 | 已套用（受控）・N 個位號無座標 |
| 量測紀錄 | 舊資料／待判定／已被修正／無法確認 | 琥珀 | 舊資料・未受控（已用於分析）／待管理者判定／歷史修正前版本／狀態無法確認 |
| 量測紀錄 | 範例或沒有來源 | 灰 | 未套用 |
| 座標檔 | 受控連結 | 綠 | 已套用（身分相符）／已連結 |
| 座標檔 | 舊資料回合的檢視套用 | 琥珀 | 已套用（檢視，未受控） |
| 座標檔 | 已選取但沒用到目前回合 | 灰 | 未套用（已選 料號 版次，原因） |
| 座標檔 | 座標檔不存在或身分不符 | 紅 | 不存在（已連結）／不符原因 |

不再單獨顯示「已選取」：選取屬於匯入表單（`#placeState`），不是回合狀態。

## 6. 驗收

- 空座標清單不含「於匯入時上傳」。
- 量測列能看出尚未搭配與座標檔不存在，並可用帶筆數的快速篩選找到。
- 從座標列匯入時，料號、版次、面別已帶入。
- `node --test tests/record-picker-layout.test.mjs tests/record-proof-ui.test.mjs tests/record-catalog-picker.test.mjs tests/records-ui.test.mjs tests/ui.smoke.test.js`
