# RFC：開啟頁面一律空白（不自動載入資料、不還原紀錄）

- **狀態**：已核准並實作（v10.27.0）
- **日期**：2026-11-13
- **基準版本**：`spi-spc.html` v10.25.1
- **參考依據**：[`AGENTS.md`](../AGENTS.md)、[`docs/spec-ui-copy-rfc.md`](spec-ui-copy-rfc.md)
- **測試**：`tests/empty-default.test.mjs`

---

## 1. 摘要

使用者登入後開啟分析台時，畫面一律是空白：沒有回合、沒有圖表、沒有問題清單、沒有報告，也沒有可匯出的內容。資料只有在使用者自己匯入檔案、從資料庫開啟量測紀錄、開啟分享連結，或按下「載入範例資料」後才會出現。上次載入的資料不會因為重新整理或重新登入而回來。

改版前的行為：每次開啟都先載入兩個範例回合，再從瀏覽器 IndexedDB `spi-spc` 還原上次的回合（提示「已還原上次的 N 個試產回合」）。另外，上次的料號、座標檔與鋼板／規格設定也存在 `localStorage`。

使用者確認的決策（2026-11-13）：

- 每次開啟或重新整理頁面都會清空，不是只在新登入時清空。
- 只清除與資料有關的紀錄，偏好設定保留。
- 範例資料保留，但只能由按鈕載入。

## 2. 範圍

**納入**

- 開啟時沒有任何回合（雲端版與離線單檔版都一樣）。
- 回合與資料相關設定不再寫入瀏覽器。
- 開啟時清除舊版留在瀏覽器的資料。
- 所有分頁、報告預覽與每個輸出動作都有空白狀態。
- 提供明確的「載入範例資料」按鈕。

**不納入**

- 登入 cookie `spi_auth`（12 小時、HttpOnly）：維持不變，否則無法保持登入。
- 雲端 D1／R2 的資料（量測紀錄、料號規格、問題案例、分享）：維持不變，照常列出供開啟。
- 舊版瀏覽器紀錄 `LocalRec`（IndexedDB `spi-records`）：維持唯讀查閱。
- 保留的偏好設定：`spi-theme`、`spi-collapsed`、`spi-vendor`、`spi-profiles`、`spi-ai-config`、`spi-ai-models`、`spi-perf`。
- 統計、偵測規則、門檻與慢速模擬基準都不變。
- 不自動重新開啟「上次使用」的雲端紀錄。

## 3. 使用者故事

- 身為已登入的分析人員，我希望開啟時是空白的，才不會把範例或上一次的資料誤認成這次要判定的批次。
- 身為在共用電腦上作業的分析人員，我希望上一位使用者的資料不會再出現，才不會讓料號與量測值外流。
- 身為講師，我希望按一下就能載入範例資料，才能繼續做示範。

## 4. 功能需求

- **FR-1.** 開啟頁面時沒有任何回合，也不執行分析或問題偵測。
- **FR-2.** 回合與量測列不寫入瀏覽器儲存空間，也不從瀏覽器讀回。
- **FR-3.** 開啟時刪除舊版留下的資料：IndexedDB `spi-spc` 的 `runs`、IndexedDB `spi-spc-cache`，以及 `localStorage` 的 `spi-stencil`、`spi-place`、`spi-last-part`。
- **FR-4.** 每次開啟時，資料相關設定都回到出廠預設：鋼板 120 µm、高度公差 75–125 %、預設階梯區域、沒有開孔修改、沒有座標檔、料號空白、規格來源為「未定義」。
- **FR-5.** 沒有回合時，每個分頁都顯示空白狀態，不顯示由資料算出的圖表、表格、KPI、判定或 3D 模型。沒有資料時不顯示「尚未套用料號規格」鎖定頁。
- **FR-6.** 沒有回合時，所有輸出動作（PDF、列印、Markdown、CSV、XLSX、3D 快照、郵件 PDF、分享、AI 分析）都不產生檔案、不送出請求，並提示「目前沒有量測資料」。
- **FR-7.** 空白狀態提供「載入範例資料」按鈕，按下後載入兩個既有範例回合與示範規格，並開啟問題頁。
- **FR-8.** 在沒有回合時匯入檔案、開啟雲端紀錄或開啟有效的分享連結，該資料就成為目前回合，分析流程與改版前相同。
- **FR-9.** 回合說明改為「已載入的資料只在這個分頁，重新整理或重新登入後會清空」，不再出現「已還原上次的…回合」提示。
- **FR-10.** 可以刪除最後一個回合，刪除後回到空白狀態。
- **FR-11.** 「不納入」中列出的偏好設定，重新開啟後仍然保留。

## 5. 驗收條件

| 需求 | Given | When | Then |
|---|---|---|---|
| FR-1 | 瀏覽器沒有任何保存的資料 | 登入並開啟頁面 | 回合選單是空的，總覽顯示「尚未載入分析資料」，也沒有出現計算中提示 |
| FR-2/3 | 瀏覽器留有 v10.25.1 保存的回合 | 開啟新版 | 頁面是空白的，IndexedDB `spi-spc` 中已沒有 `runs` |
| FR-2 | 載入範例或匯入資料後 | 重新整理 | 頁面是空白的，也沒有還原提示 |
| FR-2 | IndexedDB 無法使用（私密瀏覽） | 開啟頁面 | 仍是空白狀態，不出現錯誤對話框 |
| FR-4 | 之前設過鋼板 100 µm 並選了座標檔 | 重新整理 | 鋼板顯示 120 µm，沒有座標檔 |
| FR-5 | 沒有回合 | 逐一進入各分頁 | 每頁顯示空白狀態，主控台沒有例外 |
| FR-6 | 沒有回合 | 按任何匯出、列印、分享或 AI 按鈕 | 不下載、不送出 `/api/share` 或 `/api/analyze`，並顯示「目前沒有量測資料」 |
| FR-7 | 沒有回合 | 按「載入範例資料」 | 出現「試產 1 · 鋼板 V1」與「試產 2 · V2 BGA 加大＋奈米塗層」，問題頁列出偵測結果 |
| FR-8 | 沒有回合，網址帶有有效的分享代碼 | 開啟頁面 | 開啟分享的回合，而不是範例 |
| FR-10 | 只剩一個回合 | 刪除它 | 目前分頁顯示空白狀態 |
| FR-11 | 深色主題、欄位對應設定檔、AI 設定 | 重新整理 | 三者都仍然生效 |

## 6. 邊界情境

- **直接連到分析分頁**（例如 `#control`）：該分頁顯示空白狀態，不會反覆跳轉。
- **iPhone／iPad 雙欄**：兩欄都顯示空白狀態。
- **回合比較只有 0 或 1 個回合**：顯示「需要至少兩個試產回合」，不出現 NaN。
- **清除舊資料失敗**（被封鎖、空間不足、私密瀏覽）：直接略過。因為新版已不再讀取這些資料，頁面仍然是空白的。
- **舊版只存在瀏覽器裡的回合**：會被 FR-3 刪除。自 v10.3.0 起，新的量測都只存在雲端，CHANGELOG 會註明這一點。
- **未登入或登入逾時**：維持不變，由伺服器導向 `/__login`。
- **離線單檔版**：同樣從空白開始，並提供範例按鈕。
- **回焊後檢查（AOI）上傳與範例**：沒有回合時提示「目前沒有量測資料」，不會出錯。

## 7. 非功能需求

- **效能**：開啟時不再產生範例資料、不做分析，可互動時間不會變長。5 萬筆的 `analyze`／`detectIssues` 預算（< 3 秒）不變。
- **隱私**：開啟頁面後，瀏覽器裡沒有任何來自回合的量測列、料號、批號或座標檔。問題偵測快取只放在這次開啟的記憶體中。
- **版面**：空白狀態沿用既有的 UI 驗收矩陣。
- **文案**：依 `docs/spec-ui-copy-rfc.md`，只用中文。

## 8. 實作對照

- 開機改用 `clearRuns()`，不再呼叫 `initRuns(false)`、`restoreRuns()`。
- 刪除 `saveRunsNow`、`restoreRuns`；`saveRunsSoon` 只更新說明文字；`purgeLegacyData()` 負責清除舊資料。
- `persist()`、`placeSave()`、`placeLoad()` 不再存取 `localStorage`。
- `DetCache` 改為記憶體快取，讀出時回傳副本。
- `gateOn` 在沒有資料列時不鎖定分頁。
- 新增 `needData()`，掛在 `save`、`needSpec`、列印、PDF、精簡 PDF、3D 快照、郵件 PDF、交付包與 AI。
- 新增 `loadSample()`；任何帶有 `[data-load-sample]` 的按鈕都會呼叫它，`[data-goto-import]` 則前往匯入。
- 3D、統計異常、形貌、LISA、DFM 等卡片補上空白狀態。
- 測試替身：`SPI_TEST_HOOK.bootSample === true` 時，開機沿用範例資料。只有既有的範例資料測試使用，正式頁面不會設定它。

## 9. 風險

- **既有測試假設開機就有範例資料**：在這些測試的測試替身中加上 `bootSample: true`，範例資料本身不變，統計基準也不受影響。
- **使用者重新整理後會失去已載入的資料**：這是預期行為，已寫在回合說明與 CHANGELOG。
