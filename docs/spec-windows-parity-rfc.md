# Feature Spec: Windows 對照候選項目

## 1. Summary

已登入的品質工程師用同一批 SPI 時，圖算不出、證據被抽樣、或開孔沒蓋滿，畫面仍可能像正常結果。本迭代只把候選行為寫成可驗收規格。成功條件：點名的那一項上線後，工程師能從畫面或報告預覽判定通過或失敗。

來源：私人倉庫 [spi-spc-analyst-windows](https://github.com/chenchihcu/spi-spc-analyst-windows) `main`（2026-10-27）。對照本專案 `907af02`（v10.8.1）。桌面契約正文已含鋼板幾何，不以文件抬頭日期 2026-07-27 為準。

## 2. Scope

**In scope（本迭代）**

- 這份規格本身。
- 下列 FR 的可觀察行為文字，供日後點名驗收。本迭代不實作任何 FR。

**點名之後**

- 只做被點名的那個編號，並可改它需要的測試與版本號。

**Out of scope**

- 本迭代不改 [spi-spc.html](../spi-spc.html)、測試、migration 或版本號。
- 新量測只寫 D1＋R2。未登入的寫入直接失敗。
- Qt 側欄、手機改成桌面殼、機台 PASS／NG 參與判定、本機 SQLite。
- 改變 EWMA／CUSUM 界限，或把桌面「整條序列 σ」搬過來（桌面 open #14）。
- 單邊規格的 Pareto，以及桌面尚未定義的叢集座標、階梯鋼板面積 OOS 率（open #13 與空欄位）。
- PPTX、密度圖、子群比較圖、零件類型 ANOVA 圖、第二個供應商下拉、供應商代碼主檔、知識庫 xlsx 匯入流程。
- 內建範例回合改走「未存規格即鎖定」。範例仍用內建示範規格。

## 3. User Stories

對象除非另寫，都是已登入、正在看一個試產回合的品質工程師。故事與 FR 不一致時，以 FR 為準。

- 工程師希望算不出的圖寫出原因，以免把空白當成製程正常。
- 工程師希望每條發現標明是計算、圖表、規則推論或未納入，以免把規則當成已證實原因。
- 工程師希望報告寫明空間證據未納入的原因，以免沒有座標仍讀到空間結論。
- 工程師希望抽樣圖同時寫出分析筆數與顯示筆數，以免把圖上的點當成全部資料。
- 工程師希望只切頁時數字不變，改篩選後數字才變。
- 工程師希望規則清單標出版本；規則檔不可用時看到錯誤，而不是規則消失。
- 工程師希望問題卡摘要用該問題自己的量測項目，不跟頂部篩選或問題清單篩選走。
- 工程師希望在進階分析切換關係圖，回到管制圖時原圖種還在。
- 工程師希望開孔沒蓋滿時能力標成待查，並看到未涵蓋焊墊，趨勢仍可看。
- 工程師希望立榮、振順豐的位號尾碼能分成子板；通用格式的完整位號保持原樣。
- 工程師希望雙邊規格能看到分側 PPM 與合併 DPMO；缺規格或沒有有效樣本時看到不可算。

## 4. Functional Requirements

- **FR-1.** 熱圖或 LISA 缺少有效座標時，圖卡以文字標示不適用與缺座標。
- **FR-2.** 問題卡的「事實」與「推論」各自標出一種證據種類，交叉驗證列也各自一種。種類只有：統計計算、圖表證據、規則推論、未納入。同一塊不同時出現兩種。
- **FR-3.** 沒有有效 X／Y 時，報告預覽的空間證據標成未納入並寫出原因。
- **FR-4.** 顯示點數少於分析筆數時，圖旁與「資料範圍揭露」同時寫出兩個筆數。
- **FR-5.** 回合、規格版、篩選與特徵不變時，切頁後總覽上名稱以「CPK」開頭的 KPI 不變。
- **FR-6.** 交叉驗證的「SPI 製程對應知識庫規則」標出規則版本。規則檔不可用時顯示無法載入。不在問題偵測頁另做一份規則目錄。
- **FR-7.** 問題卡摘要與總覽優先問題使用該問題自己的量測項目。
- **FR-8.** 關係圖只出現在進階分析頁，不另開頁籤。切換關係圖不改變管制圖頁目前的圖種。
- **FR-9.** 開孔覆蓋率未滿時，總覽與製程能力頁名稱以「CPK」開頭的 KPI，以及總覽「不良 PPM（全部判定項目）」與製程能力頁名稱以「超規 PPM」開頭的欄位，都標成待查。有逐元件群組表時，表內欄名「Cpk」與超規 PPM 也標成待查。趨勢仍可看，並列出未涵蓋焊墊。此處的良率是「不良 PPM」，OOS 是「超規 PPM」。
- **FR-10.** 立榮與振順豐的位號尾碼在總覽「不良柏拉圖」或統計資料頁分成子板組，組名含該尾碼數字。通用格式不去尾碼。
- **FR-11.** 雙邊規格且有有效樣本時，統計資料與報告顯示低於下限 PPM、高於上限 PPM、合併事件 DPMO、合併板 DPMO。

已從需求刪除、改放到範圍外或非功能：原「切頁不重算」裡的 3 秒門檻（改列非功能）、原「標準差只稽核」（沒有新的畫面行為）、原 PPTX（未點名前不是需求）。重複位號、標準差為 0、樣本少於 10、只有時間、用 PanelId 代替板號，未列入本規格。

## 5. Acceptance Criteria

勾選標籤是「9. 資料範圍揭露」。報告預覽的標題是「八、資料範圍揭露與未納入證據」。勾選「5. 製程能力」對應預覽標題「四、製程能力分析」。驗收看標題，不要求改編號。

### FR-1

- **Given** 內建範例回合 **When** 打開熱圖 **Then** 圖上有可讀的點或色階，不是缺座標說明。
- **Given** 已套用料號規格、但沒有有效座標的雲端回合 **When** 打開熱圖 **Then** 圖卡文字含「缺座標」或同等的不適用說明。
- **Given** 上一條那個沒有有效座標的雲端回合 **When** 打開 LISA **Then** 同樣是不適用文字，畫面沒有 NaN。
- **Given** 非範例回合、該料號沒有已存規格 **When** 打開分析頁 **Then** 仍是現有鎖定頁，鎖定頁上沒有熱圖。

### FR-2

- **Given** 問題卡已展開 **When** 看「事實」 **Then** 證據種類只有一種，且是統計計算或圖表證據。
- **Given** 同一張卡 **When** 看「推論」 **Then** 證據種類是規則推論，文字含「需現場驗證」。
- **Given** 交叉驗證有一列 **When** 看該列 **Then** 四種證據種類只出現一種。
- **Given** 同一內建範例、只加上證據種類 **When** 比較問題卡順序 **Then** 嚴重、警示、資訊的先後與加標籤前相同。

### FR-3

- **Given** 沒有有效 X／Y 的回合，且勾選資料範圍揭露 **When** 產生報告預覽 **Then** 「資料範圍揭露與未納入證據」寫明空間熱圖與 LISA 未納入及原因。
- **Given** 同一預覽 **When** 查看空間段落 **Then** 沒有當作有效證據的熱圖或 LISA 圖。
- **Given** 取消資料範圍以外的某一報告章節 **When** 再產生預覽 **Then** 畫面上的問題清單仍在；預覽裡不出現該章。

### FR-4

- **Given** 交叉驗證散佈的分析筆數大於畫面上的點數 **When** 看圖旁文字 **Then** 兩個筆數都在，且較大的那個標成分析筆數。
- **Given** 同一回合 **When** 打開已勾選的資料範圍揭露 **Then** 同一組兩個筆數出現在該標題下。
- **Given** 某個圖的顯示筆數等於分析筆數 **When** 看圖旁文字 **Then** 不寫「已抽樣」。

### FR-5

- **Given** 記下總覽上名稱以「CPK」開頭的 KPI **When** 只切到管制圖再切回總覽 **Then** 該 KPI 與切頁前相同。內容是「待查」時，切頁後仍是「待查」。
- **Given** 改了元件群組或量測項目 **When** 回到總覽 **Then** 該 KPI 等於新條件下的結果。與切換前內容相同仍算通過。

### FR-6

- **Given** 規則檔可用 **When** 打開交叉驗證 **Then** 「SPI 製程對應知識庫規則」標題旁看得到規則版本，不必再展開細項。有引用規則時，展開後仍看得到原本的規則說明。
- **Given** 同一內建範例，只改規則說明、不改偵測門檻 **When** 比較問題卡的嚴重、警示、資訊件數 **Then** 件數與改說明前相同。
- **Given** 規則檔遺失或指紋不符 **When** 打開交叉驗證 **Then** 畫面寫出無法載入，不顯示成「沒有規則」。

### FR-7

- **Given** 一張問題的量測項目與頂部目前選的量測項目不同 **When** 展開該問題卡 **Then** 摘要寫的是該問題的量測項目。
- **Given** 同一問題出現在總覽優先問題 **When** 看該列 **Then** 量測項目與問題卡相同。
- **Given** 只改問題清單的嚴重度或面向篩選 **When** 看總覽優先問題的標題 **Then** 標題與篩選前相同。
- **Given** 背景偵測跑完 **When** 再看該問題卡 **Then** 摘要仍在，且與總覽同一問題的量測項目一致。
- **Given** 在管制圖改了頂部「量測項目」 **When** 看管制圖 **Then** 圖上寫出目前頂部的量測項目。回到問題卡後，摘要仍是該問題自己的量測項目。

### FR-8

- **Given** 在進階分析，所選圖的軸與「高度 × 面積」散佈、「面積比 × 轉移效率」、「量測項目相關矩陣」都不同，且選定特徵尚未共線到既有 Hotelling 會拒絕計算的程度 **When** 切換規格散點、四象限、相關、平行座標或 Radar **Then** 該圖只出現在進階分析頁內的一個圖框，不另開頁籤，也不取代這三個既有圖。
- **Given** 管制圖目前是某一圖種 **When** 到進階分析切換關係圖再回到管制圖 **Then** 圖種與離開前相同。
- **Given** 關係圖使用的軸與「高度 × 面積」散佈、「面積比 × 轉移效率」或「量測項目相關矩陣」相同 **When** 顯示 **Then** 不新增該關係圖。
- **Given** 關係圖的軸與「高度 × 面積」散佈、「面積比 × 轉移效率」、「量測項目相關矩陣」都不同，且選定特徵共線到既有 Hotelling 會拒絕計算的程度 **When** 打開該關係圖 **Then** 該圖寫出拒絕原因，不畫成可判讀的相關圖或 Radar。這三個既有圖維持原樣。

### FR-9

- **Given** 鋼板與開孔已有一組開孔，再匯入可解析幾何，匹配後覆蓋率未滿 100% **When** 看總覽與製程能力 **Then** 兩頁名稱以「CPK」開頭的 KPI 顯示「待查」，不顯示 Cpk 數字。
- **Given** 該覆蓋率未滿的回合 **When** 看總覽「不良 PPM（全部判定項目）」與製程能力頁名稱以「超規 PPM」開頭的 KPI **Then** 這些位置顯示「待查」，不顯示 PPM 數字。
- **Given** 該覆蓋率未滿的回合，且製程能力頁有逐元件群組表 **When** 看表內欄名「Cpk」與名稱以「超規 PPM」開頭的欄 **Then** 這兩欄顯示「待查」，不顯示數字。
- **Given** 該覆蓋率未滿的回合 **When** 看趨勢或管制圖 **Then** 趨勢仍可看。
- **Given** 該覆蓋率未滿的回合 **When** 看面積比、DFM 與 3D 外框 **Then** 列出未涵蓋焊墊，且量測座標與匯入前相同。
- **Given** 幾何檔是空檔、損壞，或只有文字層、圖例層 **When** 匯入 **Then** 畫面寫出拒絕原因，開孔表與匯入前相同。
- **Given** 旋轉不是 90° 的倍數 **When** 匯入 **Then** 拒絕，開孔表與匯入前相同。
- **Given** 已有逐焊墊 CSV 開孔 **When** 再匯入幾何 **Then** CSV 開孔仍在，幾何不覆蓋它。
- **Given** 覆蓋率以幾何檔中的相異焊墊為分母、對上量測焊墊為分子，且達到 100% **When** 看總覽與製程能力 **Then** 兩頁名稱以「CPK」開頭的 KPI、總覽「不良 PPM（全部判定項目）」與製程能力頁名稱以「超規 PPM」開頭的欄位都顯示數字，不顯示「待查」。有逐元件群組表時，欄名「Cpk」與超規 PPM 也顯示數字。

### FR-10

- **Given** 立榮或振順豐位號帶 `_數字` 或 `-數字` **When** 看總覽的「不良柏拉圖」或統計資料頁 **Then** 其中一處出現組名含該數字的一組。
- **Given** 通用格式的完整位號含同樣尾碼 **When** 匯入並分析 **Then** 位號與檔案中的完整值相同，不另開子板組。

### FR-11

- **Given** 體積有雙邊規格且有效樣本大於 0 **When** 看統計資料 **Then** 四個數值各有標籤：低於下限 PPM、高於上限 PPM、合併事件 DPMO、合併板 DPMO。不取代既有的「超規 PPM」與「不良 PPM（全部判定項目）」。
- **Given** 同一回合，勾選「5. 製程能力」 **When** 看報告預覽「四、製程能力分析」 **Then** 同一組四個標籤與數值出現。不新增報告勾選。
- **Given** 該特徵沒有規格，或有效樣本為 0 **When** 看這四欄 **Then** 顯示不可算與原因，不用 0 代替原因。
- **Given** 雙邊規格、有效樣本大於 0，且某一側沒有超規 **When** 看該側 PPM **Then** 該側可以顯示 0。
- **Given** 只有單邊規格 **When** 看這四欄 **Then** 顯示不可算。不產生全 0 的有效圖，也不做單邊 Pareto。

## 6. Edge Cases and Failure Modes

- **Case:** 未登入者上傳量測或幾何。 **Behavior:** 寫入失敗，不產生新的雲端紀錄或開孔版本。
- **Case:** 幾何檔無法在這次操作內解析完。 **Behavior:** 拒絕並保留原開孔表。不留下半套開孔。`[OPEN_QUESTION]` 檔案大小上限由使用者另定；定案前不自訂位元組門檻。
- **Case:** 座標檔已因單位錯誤被拒絕。 **Behavior:** 幾何匯入不寫入量測座標，也不把該座標檔改成已接受。
- **Case:** 問題頁在手機寬度收起摘要列。 **Behavior:** FR-7 的摘要仍在問題卡本體內可讀。
- **Case:** 320px 寬、深色主題。 **Behavior:** 新文字可換行，整頁不橫向溢出；狀態除了顏色還有文字。未實際看過的標 `not verified`。
- **Case:** 同一新功能做了桌面與手機兩份節點。 **Behavior:** 該 FR 驗收失敗。記錄庫既有的桌面表與手機卡除外。

## 7. Non-Functional Requirements

- **Performance.** 任何改到 `analyze` 或 `detectIssues` 的項目，5 萬筆各仍須少於 3 秒，且同一黃金資料的既有統計數字與改動前一致。會改首次載入或主執行緒的項目，另對建置產物量測：LCP ≤ 2.5 秒、INP ≤ 200 毫秒、CLS ≤ 0.1，取第 75 百分位。這三項目前是 `not verified`。
- **Security.** 未登入寫入失敗。幾何與原始檔只進該登入者的 R2，刪除權仍限上傳者。送給 AI 的內容仍只有摘要。
- **Accessibility.** 新文字對比至少 4.5:1（WCAG 2.1 AA），含深色與報告預覽。新按鈕不寫行內最小高度；觸控目標維持既有 44px 規則。
- **Compatibility.** 驗收用建置產物，寬度 1440、820、390、320，明亮與深色各看。介面文字為繁體中文。

## 8. Dependencies

- 既有登入、D1＋R2、料號規格版本、報告預覽與十個章節勾選，都已在 v10.8.1。
- 熱圖、LISA、交叉驗證散佈、問題卡、總覽、進階分析、鋼板與開孔、加工廠下拉，都已存在。不加頁籤。FR-8 的關係圖只放在進階分析頁。
- 桌面倉庫只作對照，不是執行時依賴。
- `[ASSUMPTION]` FR-6 的規則檔放在版控的靜態 JSON。xlsx 匯入不在本規格。

## 9. Risks and Mitigations

- **Risk:** 覆蓋率未滿時，舊的振順豐回合不能看趨勢。 **Mitigation:** FR-9 要求趨勢仍可看；看不到則該項不合併。
- **Risk:** 證據種類或關係圖改變問題排序或管制圖圖種。 **Mitigation:** FR-2、FR-8 的對照條件失敗則不合併。
- **Risk:** 實作時順手修改 EWMA／CUSUM 界限。 **Mitigation:** 不在任何已列 FR 的範圍內。界限與改動前不同即失敗。
- **Risk:** 介面流程審查未看 320px 與深色（`NOT TESTED`）。 **Mitigation:** 改完畫面後再審一次動線，不能只引用該次審查（對話 f927173c-2705-4a04-b723-af8311ad1981）。

## 11. Success Metrics

- **Leading:** 被點名的 FR 有一筆驗收紀錄，寫明資料是內建範例或哪一筆雲端紀錄，以及該 FR 的 Then 是否成立。
- **Lagging:** 被點名的 FR，其 Then 在該 FR 指定的畫面上成立。不因本指標另加該 FR 沒有寫的報告欄位。
