# 元件分析範圍（v10.26.0）

## 1. 摘要

工程師要判讀「某一個元件」的錫膏印刷表現。在分析設定列選擇元件群組或單一元件後，所有分頁、圖表、報告與匯出只呈現該範圍的結果；仍以全板資料計算的區塊明確標示「全板分析，不隨元件範圍變動」。成功條件：沒有任何頁面在元件標示下顯示全板數字。

## 2. 範圍

**納入**
- 三層範圍：全部元件 → 元件群組 → 單一元件（一個位號，所有板、所有焊墊）。
- 分析設定列（桌機列與手機面板）的可搜尋元件選單，跟隨元件群組連動。
- 選了元件時，每個分頁上方顯示範圍提示列，一鍵清除。
- 捷徑：問題地圖零件明細「只分析此元件」、製程能力焊墊 Cpk 排名「只分析此元件：U2」。
- 一致化所有讀取端：總覽、管制圖、製程能力、3D／2D、製程跡象、問題偵測清單、報告預覽、PDF／列印頁首、郵件、AI 摘要、分享連結、問題 CSV／Markdown、統計異常點清單。
- `AGENTS.md` 規則「分析範圍一致」與對應測試、突變檢查工具。

**不納入**
- 同時選多個元件、兩個元件並排比較。
- 對元件子集重跑問題偵測（小樣本誤報率未經 `test:slow` 校準）；新增偵測規則或門檻。
- 元件級規格（規格仍取元件所屬群組，否則全板規格）。
- 統計公式、D1／R2 結構、匯入對應與分群邏輯。
- 把所選元件存進雲端紀錄（只存在工作階段與分享連結，與元件群組相同）。

## 3. 功能需求

| 編號 | 需求 |
|---|---|
| FR-1 | 元件群組旁有「元件」選單，列出所選群組的元件（群組為全部時列全部），位號自然排序（U2 在 U10 前），附焊墊數。 |
| FR-2 | 輸入文字即依位號子字串篩選，不分大小寫；最多顯示 200 項，其餘以「另 N 個」提示。 |
| FR-3 | 選元件即設定範圍；改選其他群組時，不屬於該群組的元件自動清除。 |
| FR-4 | 以位號分群（群組＝元件）或沒有位號欄時，不顯示元件選單。 |
| FR-5 | 選了元件時顯示 `範圍：U2 · QFN-48 · 48 焊墊 ✕`；✕ 回到群組範圍。 |
| FR-6 | `analyze()` 結果（總覽、管制圖、製程能力、焊墊 Cpk、單邊 PPM、柏拉圖、熱圖、製程跡象）只用範圍內資料；規格取元件所屬群組。 |
| FR-7 | 2D 板圖、3D 錫膏模擬、對位向量、關係圖只畫範圍內資料。 |
| FR-8 | 問題偵測只列歸屬範圍內元件的發現；全板層級（批次、跨板、無法歸屬零件）的發現收在下方「全板問題」；嚴重度計數與清單一致；其他元件的發現不列。 |
| FR-9 | 每個分頁登記在 `SCOPE_PANELS`；仍以全板計算的區塊登記在 `SCOPE_BOARD_CARDS`，範圍縮小時顯示「全板分析，不隨元件範圍變動」。 |
| FR-10 | 報告、PDF、列印頁首寫明 `分析範圍：元件 U2（群組 QFN-48）`，章節用範圍內結果與範圍相關問題。 |
| FR-11 | 問題 CSV 首列加「分析範圍」、Markdown 頁首加範圍，只含範圍相關問題；統計異常點清單依範圍篩選。 |
| FR-12 | AI 摘要帶 `分析範圍` 並只送範圍相關問題。 |
| FR-13 | 分享連結保存並還原元件；回合中已無該元件時退回全部，不報錯。 |
| FR-14 | 問題地圖零件明細與焊墊 Cpk 排名可一鍵設定元件範圍。 |
| FR-15 | 範圍樣本過小時沿用既有的不適用／小樣本狀態，畫面不出現 NaN。 |

## 4. 驗收條件（摘錄，完整對應見 `tests/component-scope.test.mjs`）

- **Given** 範例資料 **When** 選 U2 **Then** `S.A.N` 等於 U2 有體積值的列數，Cpk 與只含 U2 資料的分析逐位元相同；全部範圍與改版前相同。
- **Given** 選 U2 **When** 開問題偵測 **Then** 清單只含 U2 的發現，「全板問題」只含全板層級發現，其他元件的發現不出現，標題以「元件 U2（群組 U2 BGA）：」開頭。
- **Given** 選 U2 **When** 改選群組 C 0402 **Then** 元件清除、提示列隱藏。
- **Given** 單板資料、選 C1 **When** 開總覽／管制圖／製程能力／報告 **Then** 無 NaN、無執行錯誤。
- **Given** 新增分頁未登記 `SCOPE_PANELS` **Then** 測試失敗。

## 5. 邊界情境

- 無位號欄：元件選單隱藏，群組範圍照舊。
- 同位號在多個子板：分開列為 `U2 · 子板 1`，鍵與問題地圖 `partMapKey` 相同。
- 元件跨多個群組：用全板規格，提示列顯示「群組混合」。
- 換回合或重新匯入：元件仍存在則保留，否則清除。
- 位號含 `<`、`&`：選單以 `esc()` 輸出，提示列以 `textContent` 設定。
- 規格未定義（鎖定畫面）：沿用鎖定畫面。
- 雙欄模式：兩欄共用同一範圍。

## 6. 非功能需求

- 效能：5 萬筆 `analyze`、`detectIssues` 仍 < 3 秒；範圍判斷單趟過濾，篩選函式只在範圍改變時重建。
- 無障礙：元件選單為 combobox＋listbox，方向鍵／Enter／Esc；觸控熱區 ≥ 44px；明暗主題對比 ≥ 4.5。
- 版面：1440／820／390／320px 無橫向溢出。
- 統計：不改公式、門檻、加總順序；全部範圍結果逐位元相同。

## 7. 驗證的有效性

`node tools/mutation-check.mjs` 逐一套用 `tests/fixtures/mutations-component-scope.json` 的 15 項破壞（快取鍵漏元件、分析未篩元件、問題清單未篩、全板提示缺漏、報告用全板問題、範圍不退回、統計清單未篩、提示列不顯示、分享漏元件、背景預算漏元件、AI 漏範圍、Markdown 漏範圍、搜尋分大小寫、問題地圖缺捷徑、郵件漏範圍），每項都必須讓 `tests/component-scope.test.mjs` 變紅，跑完自動還原。
