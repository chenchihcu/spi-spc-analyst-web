# RFC-SPI-UI-COPY-20261112：第二輪靜態文案刪減

**文件編號**：RFC-SPI-UI-COPY-20261112  
**狀態**：草案（本步只定契約，不改畫面）  
**範圍**：[`spi-spc.html`](../spi-spc.html) 使用者可見字串。不含統計核心、API、程式註解、路由與 migration。  
**依據**：[`docs/spec-ui-copy-rfc.md`](spec-ui-copy-rfc.md) 與 `AGENTS.md` 文案條。拿掉後合格、數值、範圍或必做動作的判讀不變，就刪。

v10.10.1 與 v10.15.2–v10.15.11 已刪教學折疊與一輪重複標籤。畫面上仍有三類剩餘字：與所在頁籤或子頁同義的標題、口號與欄位複述、指向已不存在控制項的說明。

## 1. 目標與非目標

**目標**

- 逐條列出要刪或縮短的可見字串，以及必須留下的句子，讓下一輪實作不必再猜。
- 刪字不改計算結果、欄位語意或按鈕行為。

**非目標**

- 不改公式、門檻、匯入契約、API、Schema。
- 不刪空狀態的「沒有資料」本身、錯誤、`role="alert"`、動態結果列，以及會改變判讀或必做動作的單句。
- 不重寫報告章節結構。
- 不改 `AGENTS.md`、不加路由或 migration。程式註解（含「鋼板與規格只在資料與規格 → 匯入與規格修改」那段）不在範圍。
- 本文件落地時不升 `package.json`。

## 2. 元件與資料流

唯一畫面來源是 `spi-spc.html`。靜態字在標記裡；少數在腳本賦值：`#issSub`、`#vText`、報告預覽空狀態、`#grid3dWarn`、重新匯入 toast、`updateImportWorkflow` 的閒置摘要、AI 與報告匯出標題。

刪字不改 `analyze()` 或 `detectIssues()`。`#impFlowStatus` 繼續承接動態句（正在讀取、需要修正、正式匯入需登入、請檢查欄位預覽）。只拿掉閒置時與步驟條重複的那句。五個 `h4.imp-step-title` 刪除後，步驟狀態仍由 `#impFlowSteps` 的 `[data-flow-state]` 顯示。

頁籤與子頁是位置名稱。靜態標題若只重複該名稱或只複述下方欄位，刪除。動態結果、錯誤，以及會改變判讀或必做動作的句子留下。
