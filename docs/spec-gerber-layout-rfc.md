# 板面圖檔（Gerber）與鋼板開孔（v10.30.0／v10.31.0）

## 1. 摘要

工程師手上有 PCB Gerber 與鋼板 Gerber（錫膏層），想在真實焊墊佈局上指出不良位置，並以鋼板實際開孔算面積比。現況只有座標檔的元件中心點：問題地圖每顆零件一個點，開孔尺寸來自 SPI CSV、群組手動輸入或 0.7 mm 估算。

分兩版交付：

| 版本 | 交付 |
|---|---|
| v10.30.0 | 登錄板面圖檔（錫膏層／銅箔層／板框），問題地圖畫出真實焊墊並標示問題零件，可縮放平移 |
| v10.31.0 | 由錫膏層填入每顆零件的開孔尺寸，面積比、DFM 卡與報告改用實際開孔 |

成功條件：有座標檔與錫膏層的回合，問題地圖上每顆有問題的零件落在它自己的焊墊上；對不上的零件明列，不猜。

## 2. 範圍

**納入**
- Gerber RS-274X（含 X2 屬性）解析：`FS`、`MO`、`AD`（C／R／O／P）、`AM` 巨集（基本形 1、4、5、20、21 與變數運算）、`D03` 閃光、`G36/G37` 區域、`G01/G02/G03`（G74／G75）、`LP`、`SR`、`LR`／`LM`／`LS`、`TF.FileFunction`、`TO.C`／`TO.P`、`TA.AperFunction`。
- 新紀錄類型 `layout`：每份檔一筆，綁料號、版次、面別（TOP／BOT）與圖層（`paste` 錫膏層／`copper` 銅箔層／`outline` 板框）。
- 量測回合套用板面圖檔，問題地圖改畫真實焊墊。
- v10.31.0：錫膏層開孔尺寸進入 `aperture()`。

**不納入**
- `.zip` 打包、DXF、ODB++、IPC-D-356 網表。
- 推定零件內的腳位順序；改變 `pos3D` 優先序；新增偵測規則或門檻；D1 migration。
- 依板面圖檔重寫量測列的 `x`／`y`（見 §4 第 3 點）。

## 3. 功能需求

| 編號 | 需求 |
|---|---|
| FR-1 | 管理者在紀錄庫「座標檔庫」登錄板面圖檔：料號、版次、面別、圖層、檔案。圖層依 `TF.FileFunction` 或副檔名（`.gtp/.gbp` 錫膏、`.gtl/.gbl` 銅箔、`.gko/.gm1` 板框）預選，可改。 |
| FR-2 | 同一料號、版次、面別、圖層只有一份有效檔。相同內容重傳沿用既有紀錄；不同內容回 409，需新版次。 |
| FR-3 | 伺服器解壓、核對 SHA-256，並以同一份解析程式（摘要模式）確認是 Gerber、有單位與格式、焊墊數與尺寸在範圍內；不合格回 422 並說明如何修正。 |
| FR-4 | 匯入步驟 ① 顯示所選料號、版次、面別已登錄的圖層；未登錄時顯示「未登錄板面圖檔」。正式量測上傳時帶入使用的圖檔，伺服器核對後寫入 `meta.layoutProof`。 |
| FR-5 | 開啟回合時套用板面圖檔：有 `layoutProof` 用指定檔；沒有時依料號、版次、面別查有效檔，標示「依料號版次套用」。 |
| FR-6 | 對應層級自動判定並顯示於地圖狀態列（見 §4）。 |
| FR-7 | 問題地圖有板面圖檔時改畫：板框、全部焊墊（中性色）、有問題零件的焊墊依嚴重度著色並標 ✕／!／ℹ；選取的零件加框。 |
| FR-8 | 地圖可縮放（按鈕、滾輪、雙指）與拖曳平移，「全板」一鍵復原；點選零件同既有 `pmapSelect`。零件清單按鈕保留供鍵盤操作。 |
| FR-9 | 對不上的零件列在「對不上板面圖檔的零件」，沿用既有點位或清單呈現。 |
| FR-10 | 沒有板面圖檔時，問題地圖與改版前相同。 |
| FR-11（v10.31.0） | 依零件對應時，該零件所有開孔形狀、尺寸、面積都相同才寫入回合設定 `aperture.file`（鍵同 `compKeyOf`，值 `[L, W, 形狀碼, 面積, 周長]`），來源標「鋼板檔」；尺寸不一或被清除圖形切除的零件列為「開孔尺寸不一，無法逐焊墊對應」。不改量測列。 |
| FR-12（v10.31.0） | `aperture()` 優先序：CSV 逐焊墊 > 鋼板檔 > 群組指定尺寸 > 焊墊縮減。非矩形開孔以實際面積與周長算面積比。沒有鋼板檔的列計算結果逐位元不變。 |

## 4. 對應規則

1. **逐焊墊**：圖檔帶 X2 `TO.P`（位號＋腳位），且量測列的位號＋腳位能對上 ≥ 80%。每列綁定自己的焊墊。
2. **依零件**（最常見）：只有座標檔的元件中心。每顆零件取離中心最近的 *n* 個焊墊（*n* = 該零件在量測資料中的焊墊數），條件全部成立才接受：焊墊群中心與元件中心距離在容差內、沒有焊墊被兩顆零件同時取用。圖檔帶 `TO.C` 時直接以位號分群，不需最近鄰。
3. 依零件對應不寫入 `r.x`／`r.y`：腳位順序未知，寫入會讓空間統計把推定位置當成實測。逐焊墊對應也只保存焊墊索引供地圖使用，不改分析輸入。
4. **定位**：先以原座標比對；接受率低時，以投票估計平移並試 8 種方位（4 種旋轉 × 是否鏡像），再以中位數殘差微調，接受率達門檻才採用並在狀態列寫明「已平移 Δx, Δy mm／鏡像／旋轉」。仍不足時不套用，顯示「板面圖檔與座標檔對不上」與數字。
5. 用來對應的焊墊：有錫膏層用錫膏層（只有印刷開孔，沒有導通孔與鋪銅）；只有銅箔層時排除 X2 標為導通孔與導體的物件，並提示可能誤含導通孔。

## 5. 資料

- `records` 沿用既有欄位：`kind='layout'`、`part`、`rev`、`side`；`meta` 存 `layer`、`unit`、`pads`、`bbox`、`parser`、`fileFunction`。原始檔 gzip 存 R2 `records/{id}`。
- 回合 `run.info.layout`：`{level, ids:[{id,sha256,layer}], source:"proof"|"lookup", tf, matched, unresolved, geom}`；`geom` 為精簡幾何（焊墊中心、外框、形狀碼，必要時多邊形；板框線段），供重開時繪圖，不再下載原檔。
- 回合設定 `cfg.aperture.file`（目前回合為 `S.aperture.file`）：鋼板檔開孔，經 `aperture()` 進入面積比、DFM、報告與 3D；分享連結不帶此欄。
- 刪除與上傳權限同座標檔：只限管理者。

## 6. 驗收條件

- **Given** 合成的 2 層板（錫膏層＋座標檔）**When** 匯入並套用 **Then** 依零件層級接受率 100%，每顆零件取得的焊墊恰為它自己的焊墊。
- **Given** 錫膏層整體平移 (12.5, −3) mm 並 X 鏡像 **When** 套用 **Then** 定位找回平移與鏡像，接受率 100%，狀態列寫明。
- **Given** 錫膏層與座標檔無關 **When** 套用 **Then** 不套用，量測列不變，狀態列說明對不上。
- **Given** 兩顆零件最近焊墊重疊 **Then** 兩顆都列為對不上，不猜。
- **Given** 沒有板面圖檔 **Then** `tests/golden.test.mjs`、`tests/perf-cache.test.mjs` 不變。
- **Given** 非 Gerber 檔、缺 `FS`／`MO`、0 個焊墊、尺寸超過 1000 mm **When** 上傳 **Then** 422 並說明如何修正。
- **Given** 一般使用者 **When** 上傳或刪除板面圖檔 **Then** 403。

## 7. 非功能需求

- Worker 免費方案 CPU 10 ms：伺服器只跑摘要模式（不建焊墊幾何）。完整解析在瀏覽器。
- 解析程式單一正本 `lib/gerber-pads.mjs`，以 `tools/sync-gerber-pads.mjs` 同步到 `spi-spc.html`；測試比對兩份一致。
- 純 JavaScript：網站 CSP 不允許 WebAssembly。
- 地圖 canvas：固定 CSS 尺寸、點陣 = CSS 尺寸 × dpr、`setTransform`；觸控熱區 ≥ 44px；320px 無橫向溢出；明暗主題對比 ≥ 4.5。
- 上限：焊墊 60,000 個；外框 1000 mm；壓縮後 4 MB（沿用紀錄上限）。

## 8. 開放問題

- 實際檔案未提供（機密）。測試用依規格撰寫的合成檔；第一次套用真實檔時，以地圖狀態列的數字回報即可定位問題，不需交出檔案。
- 若依零件標示不夠精確，下一步是 IPC-D-356 網表（含腳位）以達逐焊墊對應。
