# 多視角診斷

入口為「問題偵測 → 多視角診斷」（`#issues/diagnostic`）。也可由問題卡進入；來源 ID、量測項目及結構化資料可解析的板號／實體會帶入。無明確歸屬時保留目前回合與分析範圍，不從標題猜測根因或實體。

返回來源問題會恢復原清單篩選、展開卡及按鈕焦點。手動進入與清除選取可回到回合檢視；換回合、重新匯入或重新偵測後不沿用舊問題 ID。診斷狀態只存在目前分頁，不保存成回合資料。

## 計算與連動

- 所有診斷資料先經 `scopeFilter(state)`。`buildDiagnosticModel(state, selection)` 為唯讀純計算；不寫入原始列、規格、分析設定或儲存層。
- 矩陣一頁最多 40 板 × 25 實體，板號與實體各有前後分頁。元件鍵沿用 `[figure, "comp", comp]`，相同位號在不同子板分開。子板與群組鍵以 JSON 陣列封裝，避免字串分隔符碰撞。
- 不良列由既有 `classify` 判定。一列有多個代碼仍只算一筆。分母僅含至少一項量測可依既有規格判定的列；面積沿用分類器的上限語意，高度單位未知時不判高度。完全缺量測、無適用規格及部分量測缺值分開揭露。分母為零顯示「無法判定」。
- 盒鬚圖採既有分位數函式；鬚為 1.5 IQR 範圍內實際最遠觀測值，另顯示鬚外點、焊墊筆數、板數。刮刀方向只使用實際欄位，不以板號奇偶推定。
- 製程因素按板 × 元件群組 × 實際因素值聚合量測平均，排除缺失的因素、量測、板號與群組。因素不足兩種時標示無法比較。圖表僅呈現關聯。
- 管制圖沿用既有 X̄ 計算與繪圖器，保留完整板序及缺量測板的空點。選取只改高亮，其他板留作背景；不因選取重算界限、不重跑問題偵測、不改原管制圖頁的設定。
- 位置圖區分實際焊墊座標、CAD 元件中心與無實際座標的示意排列。CAD 中心可能重疊；對應明細揭露來源，不能把中心或示意排列視為實際焊墊位置。
- 圖表均有對應資料表，矩陣、板序、因素與明細可以用鍵盤操作。異常同時有符號或文字。二維資料保留局部捲動。

本版只新增互動畫面。匯入、API、D1/R2、報告與 CSV 契約不變；不包含跨回合分析或新判異演算法。

## 驗證入口

`node --test tests/diagnostic.test.mjs` 驗證分母、缺值、多代碼、子板鍵、分層、因素聚合、來源解析、雙向分頁、焦點、回合重設、完整板序與選取前後界限不變。

範圍讀取端另由 `tests/component-scope.test.mjs` 與 `tests/fixtures/mutations-component-scope.json` 保護。完整測試、穩定製程模擬、效能與實際瀏覽器結果依各次驗收紀錄；範例資料不代表實際 SPI 回合、實體 iPhone 或正式環境已驗證。
